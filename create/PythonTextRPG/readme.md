# PythonTextRPG

## テーマ

拡張を想定した簡単なテキスト形式のRPG

## とぅどぅ

- ドラゴン以外との戦闘も想定して、jsonにbattleフラグがオンかどうかでbattle判定
- 取得アイテム名表示がターミナル上のみ。
  - {item.name}を取得しました。に変更したい。
- シナリオ変更案
  - 目覚め(start)→イベント導入(path)
    - →バトル(battle.true)→戦闘画面
      - →報酬画面(result)
      - →敗北画面(game_over)
    - →イベント
  - →ステータス開示&もう一度遊ぶ
    - →エンドロール(end)→quit
    - →転生画面(rebirth)→start

## 機能

### メインループ

ゲーム全体の心臓部
具体的な役割:

1. イベント処理
   1. 入力の受け取りとアクション
2. ゲーム状態の更新
   1. 選択に応じたゲーム状態の変更
3. 画面子の更新
   1. 最新のゲーム状態に画面を描画
