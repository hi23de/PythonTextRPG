# MyRPG

シナリオを読みすすめ、選択肢から行動を選びクリアを目指すテキストベースのRPGです。

作者の学習の為、0から作成し機能を拡張していく方式を取ります。

## Features

多様なシナリオを楽しめます。
ターン制バトルが可能です。
アイテムを収集し探索に役立てます。
クリア後にステータスを引き継いだゲームを遊べます。
